# MIVO M82 USB Clock

Синхронизация часов колонки **MIVO M82** с локальным временем Windows через USB.

Проект содержит изменённую прошивку в виде пакета секторов, исходник USB-доработки на PI32v2, утилиту синхронизации, автозапуск при входе в Windows и инструменты резервного копирования/восстановления.

На одной колонке проверены реальный USB SET/GET, правильное время на дисплее и сохранение звука. Аудиодрайвер Windows не заменяется; существующие 16 мультимедийных кнопок сохранены в HID-дескрипторе.

## Совместимость

**Название M82 само по себе недостаточно.** Проверенная платформа: JieLi BR25 / AC696x, SPI NOR 512 КиБ, flash ID `CD7013`, SFC key `077A`, база SDK `AC696N_V160`. Поддерживается только точная ревизия кода, описанная в [manifest.json](firmware/manifest.json).

Установщик сравнивает хеш всей неизменяемой области с известной оригинальной или уже установленной версией. При несовпадении он прекращает работу до стирания flash. Режима `--force` нет. Совместимость с другими аппаратными ревизиями и ключами SFC не проверена.

## Быстрый старт — если прошивка уже установлена

Нужны Windows и Python 3.11 или новее. Утилита использует только стандартную библиотеку Python и системный HID API.

```powershell
git clone --recurse-submodules https://github.com/w1ldy0uth/mivo-m82-usb-clock.git
cd mivo-m82-usb-clock
py -3 -m mivo_m82 read
py -3 -m mivo_m82 sync
```

`sync` устанавливает **локальные дату и время Windows**, затем читает RTC обратно. Успех выводится только после подтверждения результата; допустимое расхождение — не более 2 секунд. Фактически на проверенной колонке было около 0,5 секунды.

Если установлен обычный Python без команды `py`, замените `py -3` на путь к `python.exe`.

## Установка прошивки

Следуйте [пошаговой инструкции](docs/INSTALL.md): сначала резервная копия, затем проверка совместимости и запись изменённых секторов. Для работы с flash нужны права администратора и дополнительные зависимости. Для обычной синхронизации права администратора не нужны.

Прошивка распространяется как [53 248 байт изменённых секторов](firmware/mivo-m82-usb-clock-v1.0.0.sectors.bin), а не полный пользовательский дамп. Инструмент сохраняет загрузочные данные и текущую область настроек/сопряжений. Этот `.bin` **не является пакетом обновления производителя**: его нельзя просто скопировать на флешку или записать по нулевому адресу.

## Автоматическая синхронизация

Из корня репозитория:

```powershell
py -3 -m mivo_m82 install-autostart
```

Копия утилиты устанавливается в `%LOCALAPPDATA%\MivoM82Clock`; запись `MIVO_M82_Clock` добавляется в автозагрузку текущего пользователя. При входе в Windows она запускается скрыто, ждёт 10 секунд, затем до трёх минут пробует найти колонку по USB. После первого подтверждённого успеха процесс завершается. Если колонка подключена позднее, запустите `sync` вручную.

Утилита копируется отдельно от checkout, но выбранная установка Python должна оставаться на месте. В автозагрузке используется её `pythonw.exe`. Журнал: `%LOCALAPPDATA%\MivoM82Clock\autostart.log`.

Отключение:

```powershell
py -3 -m mivo_m82 uninstall-autostart
```

Отключение не меняет прошивку. Постоянная служба, облачная автоматизация и периодический фоновый опрос не устанавливаются.
