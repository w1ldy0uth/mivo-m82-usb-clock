# Воспроизводимая сборка

Нужен собственный оригинальный дамп совместимой ревизии. Полный дамп намеренно не опубликован. Зависимости закреплены commit-ссылками Git submodules.

```powershell
git submodule update --init --recursive
py -3 -m pip install -r requirements-build.txt
py -3 tools/build_firmware.py "D:\Backups\original-m82.bin"
```

Скрипт проверяет SHA-256 исходной статической области, распаковывает приватный дамп в `build/`, собирает PI32v2-код, изменяет HID entry/configuration length и BSS clear size, перемещает ресурсы, пересчитывает CRC и SFC-шифрование.

Результаты:

- `build/usb_clock.elf`, `.map`, `.bin` — добавленный код.
- `build/firmware/` — пересобранный пакет секторов и manifest.
- `build/patched-private-image.bin` — полный образ на базе вашего дампа, только для локального анализа. Он содержит данные устройства и не предназначен для публикации или слепой полной записи.

Для неизменённого исходника вывод `Matches published package: True` подтверждает побайтную воспроизводимость опубликованного пакета. Проверено при подготовке репозитория.

Отдельные проверки без устройства:

```powershell
py -3 -m unittest discover -s tests -v
py -3 tools/verify_firmware.py
```

`verify_firmware.py` собирает прошивочный код, исполняет 24 сценария в PI32v2-симуляторе с моделями API и сравнивает собранные байты с опубликованным пакетом. Полный оригинальный дамп для этой проверки не нужен. Вспомогательный адаптер обходит абсолютный локальный путь к списку memory-opcodes в upstream-модели; сами файлы submodule не изменяются.

После изменения ассемблерного кода не считайте прежнюю аппаратную проверку действительной для новой сборки. Потребуются новая проверка модели, упаковки и отдельная проверка на устройстве.
