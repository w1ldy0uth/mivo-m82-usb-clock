# Установка USB Clock Firmware

## 1. Подготовка

Проверено на Windows 11. Нужны Python 3.11+ и Git. Подключите M82 по USB с передачей данных и обеспечьте стабильное питание. На время операции подключена только одна колонка BR25.

```powershell
git clone --recurse-submodules https://github.com/w1ldy0uth/mivo-m82-usb-clock.git
cd mivo-m82-usb-clock
py -3 -m pip install -r requirements-flash.txt
```

Если репозиторий уже склонирован без зависимостей:

```powershell
git submodule update --init --recursive
```

Полная перепрошивка может нарушить запуск устройства. Инструмент поддерживает программный откат при доступном загрузчике, но восстановление через аппаратный USB-key/UART-адаптер не проверялось. Не отключайте питание во время стирания и записи. Первая установка на другой колонке требует собственного резервного дампа.

## 2. Сохранить оригинал

Откройте **PowerShell от имени администратора**, перейдите в каталог репозитория и выполните:

```powershell
py -3 tools/flash.py backup
```

Инструмент автоматически находит единственный `BR25 UDISK`/`BR25 UBOOT1.00`. Можно указать `--device`, но обычно это не нужно.

Перед чтением колонка переходит в ROM-загрузчик. RAM-загрузчик временно загружается в оперативную память. Выполняются два чтения по 512 КиБ; несовпадающие чтения считаются ошибкой. Полный дамп и JSON с SHA-256 сохраняются в `backups/`. После чтения запрашивается возврат в приложение.

Сохраните **оба файла** оригинальной копии вне каталога репозитория. JSON содержит `compatible_original: true`, если это поддерживаемая оригинальная ревизия. Дамп может содержать адреса Bluetooth и данные сопряжений — не публикуйте его.

## 3. Установить

В том же административном PowerShell:

```powershell
py -3 tools/flash.py apply
```

Установщик:

1. Проверяет тип устройства, flash ID, SFC key и хеш пакета прошивки.
2. Ещё раз делает и сохраняет два совпавших свежих чтения flash.
3. Проверяет SHA-256 неизменяемой области против точной поддерживаемой ревизии.
4. Формирует целевой образ из текущего дампа, заменяя только 13 разрешённых секторов.
5. Записывает только реально изменившиеся сектора, проверяя каждый чтением обратно.
6. Читает всю flash и сравнивает её с ожидаемым результатом.

Загрузочные данные `[0, 0x2000)` и настройки `[0x67000, 0x80000)` не записываются. Все адреса жёстко ограничены в коде. При ошибке записи предпринимается возврат затронутых секторов из свежего дампа. При ошибке самого отката инструмент оставляет устройство в загрузчике; см. [RECOVERY.md](RECOVERY.md).

Нормальное окончание содержит `FULL READBACK VERIFIED`. Сообщение об отключении транспорта при `Application reset/disconnect` может сопровождать нормальный переход из загрузчика в приложение; это не заменяет предшествующее подтверждение записи.

## 4. Проверить USB и установить время

Подождите несколько секунд после перезапуска. Далее права администратора не требуются:

```powershell
py -3 -m mivo_m82 read
py -3 -m mivo_m82 sync
```

В ответе `sync` должны быть `verified: true` и новое время. Сверьте дисплей колонки и проверьте звук. Ожидаемые USB-параметры: `VID 4C4A`, `PID 4155`, HID `MI_03`; Feature Report — 17 байт, Input Report — 3 байта с 16 кнопками.

Затем при желании включите автозапуск:

```powershell
py -3 -m mivo_m82 install-autostart
```

## Если устройство не вернулось в обычный режим

Если ошибка произошла **до стирания** или запись/откат уже подтверждены, отключите и снова подключите питание/USB. При `RollbackError` оставьте устройство включённым в загрузчике и сначала выполните восстановление. Не запускайте программу производителя с произвольным бинарным файлом из этого проекта.
