# Восстановление оригинальной прошивки

Нужна ваша совместимая **оригинальная копия до первой установки**: файл `.bin` и соседний `.json` с SHA-256. Копия уже изменённой прошивки не заменяет оригинал.

При доступном BR25 UDISK/UBOOT откройте PowerShell от имени администратора и выполните из корня репозитория:

```powershell
py -3 tools/flash.py restore --backup "D:\Backups\MIVO-M82-before-backup-YYYYMMDD-HHMMSS-ffffff.bin"
```

Путь приведён как пример. Подставьте путь к своему сохранённому оригиналу.

Инструмент проверяет SHA-256 копии, точную исходную ревизию, текущее состояние кода и границы секторов. Восстанавливаются только секторы из пакета. Современные настройки и сопряжения вне этих секторов берутся из свежего текущего чтения; старые настройки из копии поверх них не записываются.

Если после ошибки программирования автоматический откат завершился сообщением `ROLLBACK VERIFIED`, код вернулся к состоянию непосредственно перед попыткой записи. Это может быть оригинал или уже установленная USB Clock Firmware.

Если возник `RollbackError`, не выключайте колонку: доступный RAM-загрузчик полезен для повторного восстановления. Сохраните вывод ошибки и свежую резервную копию, затем повторите `restore` при устойчивом USB-соединении.

Если USB-загрузчик полностью недоступен после повреждения приложения, может понадобиться аппаратный вход в Boot ROM с USB-key/UART-инструментом. Такой способ на тестовом устройстве не проверялся; гарантии восстановления обычным кабелем в этом состоянии нет. Boot ROM и начало flash наш установщик не изменяет.

После возврата оригинальной прошивки отключите автосинхронизацию:

```powershell
py -3 -m mivo_m82 uninstall-autostart
```

Полный дамп содержит данные конкретного устройства. Не загружайте его в GitHub Issues и не заменяйте им дамп другой колонки.
